04

Learning Journey

//////

Urutan tahap yang saya lewati sebagai siswa dan web developer — tanpa tanggal, karena yang penting arah perkembangannya.

  1. Stage 01

    Dasar Web: HTML & CSS

    Memulai pengembangan website dari struktur halaman dan tampilan — memahami element, layout, dan responsive design.

  2. Stage 02

    Interaksi dengan JavaScript

    Mempelajari JavaScript agar halaman tidak hanya statis: event, DOM manipulation, dan logika interaktif.

  3. Stage 03

    Membangun dengan React JS

    Mengembangkan proyek menggunakan React: memecah UI menjadi komponen, state management dengan hooks.

  4. Stage 04

    Version Control dengan Git

    Menggunakan Git untuk mencatat perubahan kode, menjaga riwayat, dan menyiapkan kolaborasi.

  5. Stage 05

    Proyek Nyata & Portofolio

    Menerapkan semua yang dipelajari ke proyek nyata — website katalog, API sederhana, dan portofolio ini sendiri.
